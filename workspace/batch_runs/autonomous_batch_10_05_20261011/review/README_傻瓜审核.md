# 傻瓜式审核入口

1. 双击 `start_review.cmd`。
2. 浏览器会打开审核页，默认显示“先看风险”队列。
3. 视频播放后直接按键：
   - `K`：保留
   - `R`：重剪（填写原片时间范围后再按 R）
   - `D`：删除
   - `U`：不确定
   - `←/→`：上一条/下一条
4. 也可以直接点击页面按钮。每次决定会自动保存到 `review\review_decisions.jsonl`。
5. 审核顺序建议：先看风险队列，再用“普通抽查”；发现同类错误后再切到“全部”。

当前风险队列包含：重叠候选合并窗口、超过 15 秒、少于 3 秒、竖屏固定裁剪、PTS 恢复源。普通候选只需按原片抽查，不需要逐条重剪。

审核结果只记录人工意见，不会自动启动人脸裁剪、关键点检测或训练。审核结束后把 `review_decisions.jsonl` 发回或告诉我，我再按结果批量重剪。
