# LoRA 论文级评测协议（v1）

## 评测分层

1. **生成正确性**：输出可解码、帧数/分辨率/seed 一致、LoRA 张量实际加载。
2. **传统客观指标**：首帧参考图 SSIM、清晰度、光流幅度、运动补偿时间误差、与目标视频的运动曲线相关性。
3. **学习型指标**：LPIPS/DINO 身份一致性、CLIP 文本对齐、VBench 动态质量、FVD/FID。当前服务器尚无对应权重，需在管理员允许的模型缓存中补齐。
4. **人工盲评**：隐藏 Base/LoRA 标签，至少 3 名评审，对身份一致性、动作正确性、手脸结构、背景稳定性和总体偏好打分。
5. **泛化评测**：训练、验证、测试必须来源组互斥；当前 epoch-1 使用了全部 3916 条数据，因此现有结果只属于训练域检查。

## 正式模型选择门槛

- 验证集至少 100 个样本，覆盖 1280×512、1280×704、704×1280 三种 bucket。
- 每个 checkpoint 使用相同 seed 集合（建议 4 个 seed），报告均值与 95% bootstrap 置信区间。
- LoRA 相对 Base 的人工总体偏好率应显著高于 50%。
- 身份一致性和时间稳定性不得下降；动态幅度不得通过“趋于静止”换取稳定性。
- 最终测试集只在模型选择完成后评测一次。

## 必做消融

- checkpoint：epoch-0、epoch-1、正式训练各阶段 checkpoint。
- rank：8、16、32。
- target modules：attention-only 与 attention+FFN。
- learning rate：5e-5、1e-4、2e-4。
- LoRA alpha：0.5、0.75、1.0。
- 训练数据：全量、去除 fallback reference、来源均衡采样。
