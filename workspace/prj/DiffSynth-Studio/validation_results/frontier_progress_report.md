# Wan2.2 LoRA 前沿化推进记录

日期：2026-07-12

## 已发现的关键问题

1. 当前 `epoch-1` 并非无条件优于 Base：三样本平均时间扭曲误差下降，但清晰度从 415.0 降至 368.8，有效运动比例从 0.969 降至 0.635。
2. `mymotion__012` 上运动活跃比例从 Base 的 1.0 降至 epoch-1/alpha-1.0 的 0.406，存在以运动抑制换稳定性的风险。
3. 现有 3916 条数据全部参与了快速训练，没有真正的未见验证集；此前结果只能证明训练域内变化。
4. 数据包含 925 个来源组，最大同源组有 568 条。随机按行划分会造成严重来源泄漏。

## 已完成的增强

- 新增 `scripts/evaluate_lora.py`：参考图 SSIM、清晰度、光流、时间扭曲误差、目标运动偏差。
- 新增 `scripts/create_grouped_splits.py`：按来源组隔离的确定性 train/val/test 划分。
- v1 划分因三段式数字 ID 未正确归组而被审计否决；对应训练在 9% 时主动中止，不作为正式结果。
- 新增 `data_splits/source_disjoint_v2/`：数字后缀 ID 从三段式开始归组，避免同系列片段泄漏。
- 完成 4 个 LoRA 设置、3 个样本、相同 seed 的消融：
  - epoch-1 / alpha 1.00
  - epoch-1 / alpha 0.75
  - epoch-1 / alpha 0.50
  - epoch-0 / alpha 1.00

## 三样本聚合指标

| 设置 | 清晰度 | 平均光流 | 有效运动比例 | 时间扭曲误差 | 目标运动 MAE |
|---|---:|---:|---:|---:|---:|
| Base | 415.0 | 1.157 | 0.969 | 0.01384 | 0.761 |
| epoch-1 / a1.00 | 368.8 | 0.857 | 0.635 | 0.01095 | 0.559 |
| epoch-1 / a0.75 | 359.0 | 1.052 | 0.792 | 0.01246 | 0.742 |
| epoch-1 / a0.50 | 371.9 | 0.985 | 0.854 | 0.01261 | 0.671 |
| epoch-0 / a1.00 | 390.0 | 0.896 | 0.750 | 0.01110 | 0.590 |

当前 Pareto 候选是 `epoch-0 / alpha 1.0` 与 `epoch-1 / alpha 0.5`。前者更清晰稳定，后者保留更多运动。正式模型不能只按单一稳定性指标选择。

## 正式训练配置

`scripts/train_wan22_lora_formal.sh` 使用 v2 来源隔离训练集、rank 16、学习率 `5e-5`、2 epochs，并每 750 个数据步保存 checkpoint。相比快速训练，学习率减半且 checkpoint 更密，以便在过平滑前早停。

## 仍需补齐的世界前沿评测

- VBench 全维度评测。
- CLIP 文本一致性、DINO/LPIPS 身份与感知一致性。
- 来源隔离验证集上的多 seed 置信区间。
- 至少 3 名评审的匿名 A/B 盲评。
- rank、target modules、学习率和数据均衡采样消融。
